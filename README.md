Oil Depot Management System

📌 Описание проекта

**Oil Depot Management System** - информационная система для автоматизации учета, контроля и прогнозирования запасов нефтепродуктов на нефтебазе.

Проект разработан в рамках курсовой работы по дисциплине **«Автоматтандыру және басқару»** в Евразийском национальном университете имени Л.Н. Гумилева.

Система позволяет централизованно хранить информацию о нефтепродуктах, резервуарах, поставщиках и покупателях, регистрировать операции поступления и отгрузки, контролировать текущие остатки и формировать аналитические данные.

Основная идея проекта - заменить разрозненный ручной учет единой информационной системой с базой данных и веб-интерфейсом.

---

🎯 Основные цели

* автоматизация учета нефтепродуктов;
* контроль текущих остатков в резервуарах;
* регистрация операций поступления и отгрузки;
* хранение информации о поставщиках и покупателях;
* контроль критического уровня заполнения резервуаров;
* анализ истории движения нефтепродуктов;
* подготовка данных для прогнозирования спроса;
* предоставление информации через веб-интерфейс.

---

⚙️ Основной функционал

📦 Учет нефтепродуктов

Система хранит информацию о:

* названии продукта;
* марке;
* плотности;
* соответствующем ГОСТ;
* идентификаторе продукта.

🛢️ Управление резервуарами

Для каждого резервуара учитываются:

* тип резервуара;
* максимальная вместимость;
* текущий объем;
* хранимый нефтепродукт.

Система автоматически рассчитывает процент заполнения резервуара.

🚚 Учет операций

Поддерживаются два основных типа операций:

* **Кіріс** - поступление нефтепродукта;
* **Шығыс** - отгрузка нефтепродукта.

После регистрации операции текущий объем резервуара автоматически изменяется.

👥 Контрагенты

В базе хранятся:

* юридическое название;
* БИН;
* адрес;
* телефон;
* тип контрагента.

Контрагент может выступать как поставщик или покупатель.

⚠️ Система уведомлений

Для контроля резервуаров предусмотрены автоматические предупреждения:

* при заполнении **90% и выше** - предупреждение о возможном переполнении;
* при уровне **15% и ниже** - предупреждение о низком остатке.

📊 Аналитика

Система позволяет получать:

* историю транзакций;
* общий объем нефтепродуктов;
* текущие остатки;
* статистику по продуктам;
* данные для анализа динамики продаж.

🏗️ Архитектура проекта

Проект построен по принципу клиент-серверного веб-приложения.

```text
┌─────────────────────┐
│      Web Browser    │
│     HTML / CSS / JS │
└──────────┬──────────┘
           │ HTTP
           ▼
┌─────────────────────┐
│      Flask App      │
│      Python         │
├─────────────────────┤
│ Controller / Routes  │
│ Business Logic      │
│ Data Processing      │
└──────────┬──────────┘
           │ SQL
           ▼
┌─────────────────────┐
│      Database       │
│      OilDepotDB     │
├─────────────────────┤
│ Oil_Products        │
│ Counterparties      │
│ Tanks               │
│ Transactions        │
│ Forecasts           │
```

Архитектура программной части основана на подходе **MVC**: Model отвечает за работу с данными, View - за пользовательский интерфейс, Controller - за обработку запросов и бизнес-логику.

🗄️ Структура базы данных

В проекте используются следующие основные таблицы:

| Таблица          | Назначение                      |
| ---------------- | ------------------------------- |
| `Oil_Products`   | Информация о нефтепродуктах     |
| `Counterparties` | Поставщики и покупатели         |
| `Tanks`          | Резервуары нефтебазы            |
| `Transactions`   | Операции поступления и отгрузки |
| `Forecasts`      | Результаты прогнозирования      |

Связи между таблицами обеспечиваются первичными и внешними ключами. Например, `Transactions` связана с нефтепродуктами, контрагентами и резервуарами через соответствующие `FOREIGN KEY`.

🚀 Установка и запуск

1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/OilDepotManagementSystem.git
cd OilDepotManagementSystem
```

2. Создание виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Пример `requirements.txt`:

```text
Flask
PyMySQL
numpy
matplotlib
```

4. Настройка базы данных

Создайте базу данных MySQL:

```sql
CREATE DATABASE OilDepotDB;
```

После этого выполните SQL-скрипт:

```text
database/OilDepotDB.sql
```

Скрипт создает основные таблицы и добавляет тестовые данные.

---

🔐 Настройка подключения

В `app.py` необходимо указать параметры подключения к MySQL:

```python
connection = pymysql.connect(
    host='localhost',
    user='root',
    password='YOUR_PASSWORD',
    database='OilDepotDB',
    cursorclass=pymysql.cursors.DictCursor
)
```

> ⚠️ Не рекомендуется хранить настоящий пароль от базы данных непосредственно в исходном коде.

Для GitHub лучше использовать переменные окружения:

```text
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=OilDepotDB
```

---

▶️ Запуск приложения

После настройки базы данных выполните:

```bash
python app.py
```

После запуска Flask-приложение будет доступно локально по адресу:

```text
http://127.0.0.1:5000/
```

Откройте этот адрес в браузере.

🔍 SQL-аналитика

Проект поддерживает не только простые SQL-запросы, но и аналитические операции:

* `JOIN`;
* `GROUP BY`;
* `HAVING`;
* `CTE`;
* `SUBQUERY`;
* оконные функции.

Например, можно определить общий объем отгруженной продукции:

```sql
SELECT
    op.Name,
    SUM(t.Volume) AS Total_Outbound_Volume
FROM Transactions t
INNER JOIN Oil_Products op
    ON t.Product_ID = op.Product_ID
WHERE t.Trans_Type = 'Шығыс'
GROUP BY op.Name;
```
